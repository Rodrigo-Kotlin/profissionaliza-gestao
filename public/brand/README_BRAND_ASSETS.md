# Profissionaliza — Pacote de Logos para PWA

## Aplicação recomendada
- Sidebar recolhida / favicon / avatar do app: logo mark.
- Sidebar expandida / login / telas institucionais: logo horizontal.
- PWA: `pwa/icon-192x192.png` e `pwa/icon-512x512.png`.
- PWA maskable: arquivos em `pwa/maskable/`.
- iOS: `apple/apple-touch-icon.png`.
- Favicon: arquivos em `favicon/`.

## Cores do sistema
- Navy: `#111744`
- Gold: `#D9B64A`
- Background: `#F8F9FF`
- Surface: `#FFFFFF`
- Text: `#141C28`

## Boas práticas
- Não distorcer ou alterar proporções.
- A logo horizontal branca deve ser usada em fundo escuro.
- Em superfícies claras, prefira o símbolo até existir versão horizontal oficial para fundo claro.
- Ícones maskable incluem margem de segurança para recortes Android/PWA.
